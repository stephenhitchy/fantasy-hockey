RinkRat Batch 6B.1 — TypeScript 6 Test Harness Hotfix

Problem fixed
-------------
The Game Center behavior test invoked `tsc` with an explicit source file while the
project root also contained tsconfig.json. TypeScript 6 reports TS5112 for that
combination and cancels the four behavior tests before they execute.

Correction
----------
The test now creates a small temporary tsconfig.json and compiles the isolated
matchup-summary utility with `tsc --project`. This works with the project's
TypeScript 6 toolchain without loading the Angular project configuration.

Runtime impact
--------------
None. This changes only the automated test harness. It does not alter Game Center,
scoring, projections, Firebase behavior, Firestore rules, or production bundles.

Verification
------------
Run:
  npm run test:game-center-hierarchy:run

Expected:
  11 tests passed
  0 failed
  0 cancelled

Then run the complete checkpoint:
  npm run verify:batch6b
