RINKRAT BATCH 6B — GAME CENTER INFORMATION HIERARCHY
Date: July 30, 2026

Purpose
-------
Make Game Center answer the manager's most important questions immediately:
- Am I winning or losing?
- What is the current score?
- How many counted starter games are complete?
- How mature is the projection?

Changes
-------
1. Added a dedicated matchup overview component above the detailed lineups.
2. Added user-relative outcome language:
   - You lead by ...
   - You trail by ...
   - You won/lost by ...
   - Your matchup is tied.
3. Added a larger desktop current-score comparison.
4. Added projected-finish and matchup-progress summaries.
5. Projection labels now describe maturity rather than implying certainty:
   pre-matchup, early, developing, late, and near-final estimate.
6. Added per-team counted-game progress to the primary overview.
7. Changed the older “Roster Progress” wording to the more precise “Counted Games.”
8. Replaced “Waiting on N roster games” badges with “N Starter Games Left.”
9. Added compact per-team progress bars and counted-game totals to the sticky mobile scorebar.
10. Added semantic aria-valuetext to desktop and mobile progress bars.
11. Added a polite outcome status announcement without making the entire card a noisy live region.
12. Added light-ice and reduced-motion styling for the new overview.
13. Kept the asynchronous six-game player-window model unchanged.

Architecture
------------
- Matchup overview and mobile additions use component-scoped styles.
- Pure matchup summary wording and stage calculations live in
  cycle-matchup-summary.util.ts rather than adding more display logic to the route.
- Child components remain Firebase-free.
- No Firestore rules, Cloud Functions, indexes, data migrations, or scoring algorithms changed.

Testing
-------
- Added 7 Game Center hierarchy contract tests.
- Added 4 behavior tests for lead/trail/win/loss/tie/bye and progress/projection stages.
- Updated the 7 Batch 6A structural tests for the new overview boundary.
- Full Batch 6B verification contains 82 named tests plus Angular and Functions builds.
