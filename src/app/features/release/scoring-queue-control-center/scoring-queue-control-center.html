Controlled rollout

Choose the intended mode

Canary and Primary use the same worker.

They share the same idempotent worker and four-task concurrency ceiling, but D1D deliberately gives only exact Internal Test Canaries a two-minute target while live NHL games are active. Primary remains on the standard cadence until shared NHL ingestion, direct-versus-canonical scoring parity, queue cost, and staged load proof are complete. D1H permits only one exact verified canonical-read Canary, and that task still calculates the direct result as an automatic fallback. The Primary proof counter resets whenever the exact canary allowlist changes, so successes from an older test group cannot unlock a new one.
