30-second rule

Six NHL games per active roster slot

  1. Each active roster slot counts six scheduled NHL team games.
  2. The seventh team game starts that slot’s next window.
  3. Different roster slots can be on different Matchup numbers.
  4. Completed windows stay completed.
Before scheduling

League setup

  1. Invite every intended manager before locking the Draft order.
  2. Confirm each manager can sign in and sees the correct team.
  3. Save the Round 1 order, Draft time, and pick clock.
  4. Generate a verified Projection V11 board that matches the league’s scoring version.
  5. Run one complete rehearsal before the real Draft.

Commissioner FAQ

Can I add a manager after the Draft order is locked?

No. Finish filling the league first. Late membership changes can invalidate the saved Draft order.

What happens when a manager’s pick timer expires?

RinkRat may use that manager’s Queue or the best legal automatic selection. Repeated timeouts can enable Auto-Draft.

Why are two players on different Matchup numbers?

Each active roster slot owns an independent six-game window. Their NHL teams can reach the next boundary on different dates.

Should I repeat an action when the page looks slow?

No. Wait for the current confirmation or failure state. Repeating a Draft, roster, or waiver action can make recovery harder.

Can I manually correct a score or waiver result?

Do not alter competition data outside the approved server tools. Preserve the evidence and report the exact expected and observed result.
