How the total is built

RinkRat scores one NHL game at a time. Every active roster slot adds together its next {{ cycleGameCount() }} NHL games. Goals and assists use diminishing returns inside each individual game, then reset when the player’s next NHL game begins.

Game 1 points + Game 2 points + Games 3–{{ cycleGameCount() }} = Cycle total

Common questions

Important scoring details

Diminishing returns reset every NHL game

A player’s first goal in tomorrow’s game is worth the full first-goal value again.

Special-teams points stack

A power-play goal receives the normal goal points plus the power-play-point bonus.

Only active slots score

Bench and IR assets remain owned by the manager but do not add points while inactive.

Official NHL statistics are the source

RinkRat uses credited goals, primary and secondary assists, shots, hits, blocks, time on ice, and goalie results from the NHL game record.

Each slot has its own six-game window

Scoring does not wait for the entire league to reach one shared calendar date.

Completed scoring stays frozen

Once a game is assigned and scored, later roster changes do not rewrite that game.
