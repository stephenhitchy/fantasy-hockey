================================================================================
HOW TO USE THIS FILE
================================================================================

Never delete a roadmap item. Change only the status marker on the first line of the item.

[ ]  NOT STARTED
[~]  IN PROGRESS
[!]  BLOCKED / NEEDS A DECISION
# [x] COMPLETED (commented out, but kept permanently)
# [-] DEFERRED OR INTENTIONALLY REJECTED

Completion example:

[ ] S1.1 Move league creation to a server-authoritative callable Function.

becomes:

# [x] S1.1 Move league creation to a server-authoritative callable Function. — Completed 2026-09-01 in Security Batch S1.

Rules for maintaining this roadmap:

1. Keep every stable task ID (S1.1, B2.3, etc.) unchanged.
2. Add the completion date and release/batch name when an item is completed.
3. Add new discoveries beneath the most relevant phase; do not renumber old tasks.
4. Do not start a lower-priority feature if a P0 integrity or security item is unresolved.
5. After every major phase, run the full regression suite, release simulator, six-team lifecycle, mobile checks, and rollback rehearsal.
6. Avoid changing Production Scoring or Projection V11 in the middle of a live season unless a calculation is objectively wrong.
7. Preserve RinkRat's identity. The goal is not to become a generic Yahoo or Fantrax clone.

Suggested task labels:

P0 = blocks safe public growth or competition integrity
P1 = needed to compete strongly in private/public beta
P2 = major retention, breadth, or growth improvement
P3 = optional, experimental, or long-term
S  = Small estimated engineering effort
M  = Medium
L  = Large
XL = Multi-release program

================================================================================
NORTH STAR
================================================================================

RinkRat should become the best fantasy-hockey experience for private and community leagues by combining:

- Fair opportunity: every active roster slot receives six scheduled NHL team games.
- Transparency: every point, game, projection, and transaction start date can be explained.
- Mobile-first usability: managers can draft, watch, compare, and manage a roster comfortably on a phone.
- Hockey personality: RinkRat should feel like a game and a hockey community, not a spreadsheet.
- Competitive integrity: no manager or commissioner can rewrite competitive truth from the browser.
- Low maintenance: managers make meaningful decisions without daily-lineup micromanagement.
- Progressive depth: beginners see the answer first; advanced users can open the full detail.

PRIMARY POSITIONING STATEMENT:

"Every starter gets six games. No schedule luck. Every point and roster move can be explained."
